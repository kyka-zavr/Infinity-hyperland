# Infinity-hyperland

[English](README.md) | [Русский](README.ru.md)

> **Это форк [Hyprland](https://github.com/hyprwm/Hyprland), а не оригинальный проект.**
> Hyprland написан vaxerski и контрибьюторами hyprwm (BSD 3-Clause), вся основа композитора принадлежит им.
> С авторами Hyprland этот форк не связан и ими не одобрен. База: **v0.57.0** (`0aa6745`).
> Всё добавленное сверху перечислено ниже и видно в истории git (`git diff upstream main`).

Wayland-композитор с **бесконечным столом**: окна лежат на одной бесконечной плоскости, экран — окно-обзор, которое двигается и масштабируется по ней. Идея взята у VXWM (Versatile X Window Manager, форк dwm; [зеркало на GitHub](https://github.com/wh1tepearll/vxwm)), здесь она встроена в ядро Hyprland, а не сделана плагином. Обычный тайловый режим остаётся, режимы переключаются на лету.

## Что добавлено относительно Hyprland

- **Режим Infinity.** Свободные окна на бесконечной плоскости. Переключение режима ничего не теряет: выйдя из Infinity, окна возвращаются на свои тайловые места.
- **Сдвиг и зум** (от 0.1x до 4x), общие для всех мониторов. Плоскость цельная: окно можно протащить с экрана на экран.
- **Переключатель окон `ALT+TAB`** с живыми превью, иконками и названиями приложений. Показывает окна всех рабочих столов на каждом мониторе, работает в обоих режимах и центрирует выбранное окно на столе.
- **Окно настроек** (`SUPER+I`): Infinity, раскладки клавиатуры (общая или по окнам, режимы Caps Lock), одна цветовая палитра для всего и редактор бинд, который работает и с бинды из вашего конфига.
- **Установщик** для Arch Linux и производных с текстовым интерфейсом (мышь там, где её поддерживает терминал): ставится рядом с установленным Hyprland и не трогает его, добавляет пункт в экран входа и использует свой каталог конфигов.

## Управление

Бинды из `hyprland/example/hyprland.lua` (главный модификатор `SUPER`):

| Действие | Клавиши |
|---|---|
| Включить / выключить Infinity | `SUPER+SHIFT+SPACE` |
| Двигать окно / менять размер | `SUPER+ЛКМ` / `SUPER+ПКМ` (перетаскивание) |
| Двигать весь стол | движение мыши при зажатых `SUPER+ALT` (или `SUPER+CTRL+стрелки`) |
| Зум | `CTRL+колесо` (или `SUPER+CTRL+=` и `SUPER+CTRL+-`) |
| Переключатель окон | `ALT+TAB`, назад `ALT+SHIFT+TAB`; стрелки, мышь, `ENTER`, `ESC` |
| Настройки | `SUPER+I` |
| Следующая раскладка | `SUPER+SPACE` |

Подробнее: [docs/ru/usage.md](docs/ru/usage.md).

## Установка (Arch Linux и производные)

```sh
git clone https://github.com/kyka-zavr/Infinity-hyperland.git
cd Infinity-hyperland
./install.sh
```

Установщик проверяет и ставит зависимости, собирает композитор (10–30 минут) и добавляет пункт **«Infinity-hyprland»** в экран входа (SDDM, GDM, greetd и др.).

- Ставится в `/opt/infinity-hyprland`; установленный Hyprland (`/usr/bin/Hyprland`, `hyprctl`) **не затрагивается**. Оба можно держать в системе и выбирать при входе.
- Конфиг отдельный: `~/.config/infinity-hyprland/`. Вы выбираете: **скопировать** нужные файлы из `~/.config/hypr` (оригинал не меняется, дальше две независимые копии) или создать **чистый** конфиг. Существующий конфиг никогда не перезаписывается.
- Удаление: `./install.sh --uninstall` (конфиги остаются).

Полное руководство: [docs/ru/installation.md](docs/ru/installation.md).

## Состояние

Проверено владельцем на реальной системе Arch Linux (экран входа, настоящая мышь и мониторы) и во вложенных сессиях. Не проверено: HiDPI, раскладки кроме dwindle при выходе из Infinity, другие дистрибутивы. Известные недочёты и планы: [docs/ru/roadmap.md](docs/ru/roadmap.md).
