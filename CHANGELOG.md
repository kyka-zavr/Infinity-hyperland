# Changelog

[English](CHANGELOG.md) | [Русский](CHANGELOG.ru.md)

Version scheme: `v<Hyprland version>-infinity.<n>`. Every release notes page also lists the versions of the sources used (generated by `scripts/release-notes.sh`).

## v0.57.0-infinity.3 (2026-11-03)

The canvas release: Infinity becomes one canvas for the whole session, and monitors are cameras onto it
(see [docs/en/design-canvas.md](docs/en/design-canvas.md)).

### Changed

- **The Infinity mode belongs to the session, not to a workspace**: turning it on or off applies to every workspace of every monitor, and to workspaces that are created or shown later.
- **The canvas is not filtered by workspaces**: while the mode is on, every monitor draws every window that its view of the plane covers, whatever workspace the window came from. Switching a workspace changes nothing on screen, and focusing such a window does not switch a workspace either. Directional focus and the focus cycle work across the whole canvas.
- **The camera lives on the canvas**: the view and the zoom moved from the per-workspace algorithm into the `InfinityCanvas` object (`view`, `zoom`, `pan`, `zoomBy`, `visibleRect(monitor)`), and visibility of a window on a monitor uses that one mapping.
- **Wheel zoom follows the pointer on any monitor**: the anchor is taken from the monitor under the cursor instead of the focused workspace's monitor.

### Fixed

- **Windows with blur or rounded corners were cut at `monitor size * zoom`** (Telegram, OBS, browsers): the monitor damage is in screen coordinates, but the blur path transformed it by the Infinity zoom, so only a part of the content was drawn at a zoom other than 1. Canvas windows now skip that transformation.

## v0.57.0-infinity.2.5 (2026-11-03)

A small release with fixes and polish before the canvas rework of release 3.

### Added

- **The window switcher follows the pointer**: the panel appears only on the monitor the pointer is on, not on every monitor.
- **Switcher animations**: the panel fades and grows in, fades out when it closes, and the selection accent slides between tiles.
- **The canvas moves with a dragged window**: in Infinity, dragging a window to the edge of a monitor pans the plane, so a window is no longer stopped by a screen border.
- **The canvas survives the mode**: leaving Infinity and entering it again returns every window to its place and size on the plane and restores the pan and zoom. A workspace that was never in the mode still starts from a clean plane.
- **The settings window is an overlay on the monitor in Infinity**: it is pinned, kept in the middle of the monitor, drawn at its normal size (the zoom does not scale it) and cannot be moved or resized, instead of being a window on the canvas. The app ids that behave this way are set by the new option `infinity:overlay_classes` (default `infinity-settings`).

### Fixed

- **The window switcher always shows the chosen window**: the workspace and the monitor it lives on are switched to, and the window is focused (and raised) explicitly after the switch.
- **New windows open in the middle of the screen at any zoom** (the settings window included): the zoom is taken into account when the window is placed; before, at a zoom other than 1 it could open on another part of the plane.
- The switcher keeps its selection on the same window when another window closes while it is open.

## v0.57.0-infinity.2 (2026-11-02)

### Added

- **Settings window** (`SUPER+I`, Qt6/QML): Infinity, keyboard, appearance, keybinds and system pages; changes apply live. Everything is stored in `settings.json` and turned into `infinity.lua`.
- **One color palette** for everything we draw (window switcher, settings window, optional window borders and shadows), editable color by color; built-in `dark` and `light` themes, your own theme files, and **templates** that export the palette to other programs.
- **Bind editor**: rebind or disable the binds of the fork, add your own, and disable or move binds from your own Lua files (new Lua function `hl.rebind`).
- **Text installer** (`./install.sh` without arguments): config choice, **keyboard layouts**, layout and Num Lock behaviour, color scheme; keyboard first, mouse where the terminal reports it (terminal emulators, the console with `gpm`).
- Installer: builds and installs the settings window, migrates the old Infinity bind block of a previous version to the settings, installs as the user so the build folder never gets root-owned files, build threads are chosen from total memory (up to 6).
- The settings window is a single instance and closes with `SUPER+I` again or `Esc`; its look follows the serpantinum rice (monospace font, rounded translucent controls, bar sliders).
- **Palettes that follow another program's file**: the built-in `serpantinum` theme follows `~/.local/state/serpantinum/qs_colors.json` live.
- **Keyboard layouts**: `infinity:kb_layout_mode` (one layout for the session or one per window), `infinity:kb_default_layout` (layout a new window starts with), `infinity:num_mode` (normal, per window, always on) and the `kblayout next|prev|<n>` message for a layout bind.
- **Logo**: an outlined infinity mark (`assets/logo/`, light and dark), shown in the README and in the settings window.

## v0.57.0-infinity.1 (2026-11-02)

First release. Base: Hyprland **v0.57.0**.

### Added

- **Infinity mode**: windows on one unbounded plane. Switching modes on all monitors at once; windows return to their tiled places when you leave the mode.
- **Pan** (mouse with `SUPER+ALT` held, keyboard `SUPER+CTRL+arrows`) and **zoom** (`CTRL+wheel`, keyboard `SUPER+CTRL+=` / `-`, range 0.1x to 4x), shared by all monitors. The plane is continuous across monitors.
- Hit testing, window dragging and resizing that follow the zoom.
- **Alt-Tab window switcher**: a panel on every monitor with live previews, application icons and names (from `.desktop` files), all workspaces, most recent first; keyboard, mouse and modifier-release control; centers the window on the canvas in Infinity mode.
- **Installer** (`install.sh`, Arch Linux and derivatives): installs into `/opt/infinity-hyprland` without touching an installed Hyprland, adds an "Infinity-hyprland" login entry, uses its own config directory (copy of the Hyprland config or a fresh one, never overwriting), supports `--uninstall`.
- **Upstream sync**: `scripts/sync-upstream.sh` and a daily GitHub check for new Hyprland releases.
- Options `infinity:pan_mods`, `infinity:zoom_mods`, `infinity:zoom_step`; layout messages `infinity ...` and `alttab`.
- English and Russian documentation.

### Changed from upstream Hyprland

- Binary is named `InfinityHyprland`; `--version` identifies the fork.
- The install rule no longer creates a `hyprland` symlink next to the binary.
