# Changelog

[English](CHANGELOG.md) | [Русский](CHANGELOG.ru.md)

Version scheme: `v<Hyprland version>-infinity.<n>`. Every release notes page also lists the versions of the sources used (generated by `scripts/release-notes.sh`).

## v0.57.0-infinity.1 (2026-11-02)

First release. Base: Hyprland **v0.57.0**.

### Added

- **Infinity mode**: windows on one unbounded plane. Switching modes on all monitors at once; windows return to their tiled places when you leave the mode.
- **Pan** (mouse with `SUPER+ALT` held, keyboard `SUPER+CTRL+arrows`) and **zoom** (`CTRL+wheel`, keyboard `SUPER+CTRL+=` / `-`, range 0.1x to 4x), shared by all monitors. The plane is continuous across monitors.
- Hit testing, window dragging and resizing that follow the zoom.
- **Alt-Tab window switcher**: a panel on every monitor with live previews, application icons and names (from `.desktop` files), all workspaces, most recent first; keyboard, mouse and modifier-release control; centers the window on the canvas in Infinity mode.
- **Installer** (`install.sh`, Arch Linux and derivatives): installs into `/opt/infinity-hyprland` without touching an installed Hyprland, adds an "Infinity-hyprland" login entry, uses its own config directory (copy of the Hyprland config or a fresh one, never overwriting), supports `--uninstall`.
- **Upstream sync**: `scripts/sync-upstream.sh` and a daily GitHub check for new Hyprland releases.
- Options `infinity:pan_mods`, `infinity:zoom_mods`, `infinity:zoom_step`; layout messages `infinity ...` and `alttab`.
- English and Russian documentation.

### Changed from upstream Hyprland

- Binary is named `InfinityHyprland`; `--version` identifies the fork.
- The install rule no longer creates a `hyprland` symlink next to the binary.
