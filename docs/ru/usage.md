# Использование

[English](../en/usage.md) | [Русский](usage.md)

## Два режима

Каждый рабочий стол находится в одном из двух режимов, и режим переключается сразу на всех мониторах:

- **Тайловый**: обычная раскладка Hyprland (dwindle, master, scrolling, monocle).
- **Infinity**: окна это свободные прямоугольники на одной бесконечной плоскости. Экран — окно-обзор над этой плоскостью. Плоскость сдвигается и масштабируется; границ и кнопки «домой» нет (потерянное окно находится через переключатель окон).

Переключение ничего не теряет:

- окно, созданное в тайловом режиме, запоминает своё тайловое место; пройдя через Infinity и обратно, оно возвращается на него;
- окно, созданное в Infinity, при возврате в тайловый режим занимает ближайшее свободное место в раскладке;
- окна, которые уже были плавающими, остаются плавающими.

Новые окна в Infinity открываются по центру видимой области и могут перекрываться.

При нескольких мониторах плоскость общая: мониторы показывают соседние части одной плоскости, расположенные так же, как мониторы стоят на столе, поэтому окно можно протащить с одного экрана на другой. Сдвиг и зум тоже общие.

## Управление

Бинды ниже берутся из `hyprland/example/hyprland.lua` (раздел INFINITY) или из блока, который установщик добавляет в ваш конфиг. Действия мышью, встроенные в композитор, работают без всяких бинд.

| Действие | По умолчанию |
|---|---|
| Переключить Infinity | `SUPER+SHIFT+SPACE` |
| Двигать окно | `SUPER+ЛКМ`, перетаскивание |
| Менять размер окна | `SUPER+ПКМ`, перетаскивание (и за край окна при включённой `general:resize_on_border`) |
| Двигать стол | движение мыши при зажатых модификаторах сдвига (встроено, `SUPER+ALT`) |
| Двигать стол с клавиатуры | `SUPER+CTRL+стрелки` (150 px за нажатие, с повтором) |
| Зум | `CTRL+колесо` вокруг курсора (встроено) |
| Зум с клавиатуры | `SUPER+CTRL+=` приблизить, `SUPER+CTRL+-` отдалить |
| Переключатель окон | `ALT+TAB`, назад: `ALT+SHIFT+TAB` |

Зум масштабирует весь стол как карту; окна сохраняют реальный размер. Зум от 0.1x до 4x. Панели и обои (поверхности layer-shell) не масштабируются. Вне Infinity колесо уходит приложению как обычно.

На настоящей мыши курсор остаётся на месте, пока вы двигаете стол, и стол движется под ним. Во вложенной сессии (абсолютный указатель) курсор следует за мышью.

## Переключатель окон

Зажмите модификатор и нажмите `TAB`: на каждом мониторе появится панель с плитками, по одной на окно **всех рабочих столов**, недавние первыми. На плитке иконка и название приложения, **живое превью** и заголовок окна. Выбор начинается с ранее использованного окна.

| Клавиша / действие | Что делает |
|---|---|
| `TAB` / `SHIFT+TAB` | следующая / предыдущая плитка |
| стрелки | двигают выбор |
| наведение мыши | выбирает плитку под указателем |
| левый клик по плитке | переходит на это окно |
| клик вне панели | отмена |
| `ENTER` | переход на выбранное окно |
| `ESC` | отмена |
| отпустить удерживаемый модификатор | переход на выбранное окно |

Быстрое нажатие `ALT+TAB` переключает на предыдущее окно, второе возвращает обратно. В режиме Infinity стол сдвигается так, чтобы выбранное окно оказалось в центре своего монитора (с учётом зума); в тайловом режиме активируется его рабочий стол. Выбор подтверждает тот модификатор, который был зажат при открытии панели (`ALT`, `CTRL` или `SUPER`; `SHIFT` только меняет направление).

## Опции

```lua
hl.config({ infinity = {
    pan_mods  = "SUPER ALT",   -- модификаторы, при которых движение мыши двигает стол; "" отключает
    zoom_mods = "CTRL",        -- модификаторы для зума колесом; "" отключает
    zoom_step = 1.1,           -- множитель зума за один щелчок колеса (от 1.01 до 2)
} })
```

## Команды

Всё это сообщения раскладки, их можно вызывать из бинд и через `hyprctl`:

| Сообщение | Что делает |
|---|---|
| `infinity toggle` / `on` / `off` | переключить режим на всех мониторах |
| `infinity pan <dx> <dy>` | сдвинуть стол; содержимое следует за дельтой (пиксели экрана) |
| `infinity zoom <k>` | умножить зум на `k` вокруг центра монитора |
| `infinity zoom <k> <x> <y>` | то же вокруг точки (координаты внутри монитора) |
| `infinity zoom <k> cursor` | то же вокруг указателя |
| `infinity probe` | отладка: какое окно под указателем |
| `alttab` / `alttab prev` | открыть переключатель окон / сдвинуть выбор |
| `kblayout next` / `prev` / `<n>` | переключить раскладку клавиатуры (см. «Раскладки клавиатуры») |

```lua
hl.bind("SUPER + SHIFT + SPACE", hl.dsp.layout("infinity toggle"))
hl.bind("ALT + Tab",             hl.dsp.layout("alttab"))
hl.bind("ALT + SHIFT + Tab",     hl.dsp.layout("alttab prev"))
```

```sh
hyprctl dispatch 'hl.dsp.layout("infinity pan 200 0")'
```

Hyprland 0.57 читает только конфиги на Lua (`hyprland.lua`); старый формат `hyprland.conf` оригинал убрал.

## Окно настроек

`SUPER+I` открывает **Infinity Settings** (приложение Qt6; также `infinity-settings` из терминала или лаунчера). Изменения применяются сразу. Страницы:

- **Infinity**: переключение режима, шаг зума, клавиши зума колесом и сдвига мышью.
- **Клавиатура**: добавление раскладок (все языки и варианты xkb), порядок, общая или своя у каждого окна раскладка, раскладка нового окна и режим Caps Lock.
- **Внешний вид**: цветовая схема и каждый её цвет, а также (по желанию) отступы, размер рамки, скругления, размытие и тени.
- **Бинды**: см. ниже.
- **Система**: громкость (`wpctl`), яркость (`brightnessctl`), Wi-Fi (`nmcli`); если программы нет, элемент неактивен.

Всё хранится в `~/.config/infinity-hyprland/settings.json`. `infinity-settings --apply` превращает его в `infinity.lua` (подключается из вашего `hyprland.lua`) и перезагружает композитор; для скриптов есть `--print`, `--get <путь>` и `--set <путь> <json>`. `settings.json` можно править и вручную.

Окно одно: повторное `SUPER+I` (или `Esc`) закрывает его, поэтому окна не копятся. `Esc` сначала выходит из текстового поля, закрывает открытый список или отменяет захват клавиш, а когда ничего такого нет, закрывает окно.

### Цветовая схема

Одна палитра красит всё, что мы рисуем: переключатель окон, окно настроек и, если включено «Manage these settings», рамки окон и тени. Тема — файл `themes/<имя>.json` с именованными цветами (`panel`, `bg`, `surface`, `surface_hi`, `well`, `text`, `subtext`, `accent`, `accent_text`, `border_active`, `border_inactive`, `shadow`, `danger`, `success`). Две темы встроены (`dark`, `light`); при правке цвета создаётся ваша копия `custom`, а свои файлы можно добавлять.

**Палитра, которая следует за другой программой.** В файле темы может быть раздел `import`: JSON-файл другой программы и отображение его ключей на наши. Встроенная тема `serpantinum` (предлагается, когда этот рис установлен) читает `~/.local/state/serpantinum/qs_colors.json` (или файл из `QS_COLORS_JSON`) и следует за ним вживую: когда рис меняет цвета (новые обои, новый пресет), вместе с ними меняются окно настроек, переключатель окон и сгенерированный конфиг; когда окно закрыто, это делает небольшой фоновый наблюдатель (`infinity-settings --watch`, запускается вместе с сессией). Правка цвета такой темы превращает её в неподвижную копию `custom`. Формат отображения: `"accent": "blue"` берёт ключ `blue`, `"panel": "mantle:f0"` берёт `mantle` с прозрачностью `f0`.

**Экспорт в другие программы.** Положите шаблон в `~/.config/infinity-hyprland/templates/`: файл `*.tmpl`, первая строка которого `@target: <путь>`, а в теле подстановки:

```
@target: ~/.config/kitty/infinity-colors.conf
foreground {{text}}
background {{bg}}
color4     {{accent}}
```

`{{имя}}` даёт `#rrggbb`; также доступны `{{имя.nohash}}`, `{{имя.rgb}}` (`92,143,255`), `{{имя.rgba}}` и `{{имя.hex8}}` (`#rrggbbaa`). Шаблоны создаются при каждом применении; необязательная «команда после применения» (например, перезагрузить панель) выполняется после них.

### Бинды

Три вида, все редактируются в окне:

1. **Бинды форка** (режим Infinity, переключатель окон, следующая раскладка, настройки, сдвиг, зум): переназначить (клик по полю и нажать клавиши; пока идёт захват, глобальные бинды не срабатывают), отключить или сбросить.
2. **Свои бинды**: любые клавиши, запускающие программу или Lua-действие.
3. **Бинды из вашего конфига**: окно показывает все бинды, которые знает запущенный композитор, в том числе из ваших Lua-файлов, и позволяет **отключить** любой или **перенести на другие клавиши**. Ваши файлы не переписываются: выбор сохраняется как данные в `settings.json` и применяется последним (`hl.unbind` / `hl.rebind`). В списке виден тип действия (`exec_cmd`, `close`, ...), а не команда: композитор не хранит текст команды.

## Раскладки клавиатуры

Раскладки перечисляются в обычной опции `input.kb_layout`, а переключаются биндом (`SUPER+SPACE` в примере конфига). Поведение задают три опции:

```lua
hl.config({ input = { kb_layout = "us,ru" } })
hl.bind("SUPER + SPACE", hl.dsp.layout("kblayout next"))   -- или "kblayout prev", "kblayout 1" (по номеру)

hl.config({ infinity = {
    kb_layout_mode    = "per_window",  -- "system": одна раскладка на всю сессию (как в обычном Hyprland)
                                       -- "per_window": у каждого окна своя раскладка, как в Windows
    kb_default_layout = 0,             -- per_window: раскладка, с которой стартует НОВОЕ окно (0 = первая); -1 оставляет текущую
    caps_mode         = "normal",      -- "normal": без изменений
                                       -- "per_window": Caps Lock ВКЛЮЧЁН в новых окнах, переключается, запоминается для каждого окна
                                       -- "always": Caps Lock всегда включён везде
} })
```

Раскладка и Caps Lock независимы: `kb_layout_mode` и `kb_default_layout` не трогают Caps Lock, а `caps_mode` не трогает раскладку. В режиме per_window раскладка запоминается и при смене обычными клавишами XKB (например `grp:alt_shift_toggle`), а не только через `kblayout`.

## Известные ограничения

- Выход из Infinity: окна, которые раньше не были плавающими, становятся тайловыми, и место подбирается по положению их центра. Если окна двигали на столе, раскладка может отличаться от исходной. Проверено только с dwindle.
- Окна на столе не обрезаются границами монитора: окно между двумя мониторами рисуется на обоих.
- HiDPI (масштаб монитора не 1) не проверен.
- Плагины Hyprland (`hyprpm`) привязаны к конкретной сборке и, скорее всего, не загрузятся.
