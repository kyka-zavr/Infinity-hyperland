# Установка

[English](../en/installation.md) | [Русский](installation.md)

## Требования

- Arch Linux или производный дистрибутив (установщик использует `pacman`). Для других дистрибутивов: ручная сборка, см. ниже.
- Видеокарта и драйвер, на которых работает Hyprland (OpenGL ES 3).
- `sudo` для установки пакетов и копирования файлов в `/opt`.
- Около 4 ГБ свободной памяти на сборку. Установщик выбирает число потоков по общей памяти (около 2 ГБ на поток, не больше 6 и не больше числа ядер); переопределить можно `--jobs N`.

## Установка

```sh
git clone https://github.com/kyka-zavr/Infinity-hyperland.git
cd Infinity-hyperland
./install.sh
```

Что он делает по порядку:

1. Проверяет список зависимостей (`installer/arch-deps.txt`) и предлагает поставить недостающие пакеты через `pacman`.
2. Подтягивает подпроект `udis86` (`scripts/fetch-subprojects.sh`).
3. Собирает композитор с лимитом памяти (`systemd-run`, если он есть).
4. Ставит в `/opt/infinity-hyprland` (`bin/InfinityHyprland`, `hyprctl`, `start-hyprland`, обёртку сессии и программу настройки конфига).
5. Добавляет пункт входа `/usr/share/wayland-sessions/infinity-hyprland.desktop`.
6. Спрашивает, какой конфиг использовать (см. ниже).

Установленный Hyprland не затрагивается: в `/usr/bin`, `/usr/local/bin` и `~/.config/hypr` ничего не пишется.

Установщик также собирает окно настроек (Qt6: `qt6-base`, `qt6-declarative`, `qt6-wayland`, ставятся вместе с остальными пакетами). Если в вашем конфиге остался старый блок бинд Infinity от прошлой версии, установщик переносит его в настройки (изменённые вами клавиши сохраняются, делается резервная копия): `infinity-hyprland-config migrate`.

### Текстовый интерфейс

Запустите `./install.sh` без параметров в терминале, и откроется текстовый интерфейс (Python `curses`, ничего ставить не нужно): выбор конфига, папка установки, потоки сборки, **языки клавиатуры** (поиск, несколько штук, варианты), **набор текста** (общая раскладка или своя у каждого окна, раскладка нового окна, режим Num Lock) и цветовая схема. В первую очередь это клавиатура (стрелки, Tab, Пробел, Enter, Esc), а **мышь работает везде, где её отдаёт терминал**: в эмуляторах терминала и в консоли Linux при запущенном демоне `gpm`. После последней страницы окно закрывается и сборка идёт в том же терминале (чтобы `sudo` мог спросить пароль). Без терминала или с любым параметром запускается обычный установщик, как раньше.

### Параметры

| Параметр | Значение |
|---|---|
| `--config copy\|fresh\|skip` | выбрать режим конфига без вопроса |
| `--prefix DIR` | поставить в другое место (по умолчанию `/opt/infinity-hyprland`) |
| `--session-dir DIR` | куда класть пункт входа (по умолчанию `/usr/share/wayland-sessions`) |
| `--jobs N` | число потоков сборки (по умолчанию: общая память в ГБ / 2, не больше 6) |
| `--yes` | не задавать вопросов (если конфига нет, создаёт чистый) |
| `--no-deps`, `--no-build` | не ставить пакеты / не собирать |
| `--uninstall` | удалить композитор и пункт входа (конфиги остаются) |
| `--plain` | никогда не открывать текстовый интерфейс |
| `--layouts us,ru,de:nodeadkeys` | раскладки клавиатуры (`код` или `код:вариант`) |
| `--kb-mode system\|per_window`, `--kb-default N`, `--num normal\|per_window\|always` | режим раскладки, раскладка нового окна (-1 = текущая), режим Num Lock |
| `--theme dark\|light` | цветовая схема |

## Режимы конфига

Композитор читает свой каталог `~/.config/infinity-hyprland/` (его задаёт обёртка сессии через `HYPRLAND_CONFIG`). Оригинальный `~/.config/hypr` только читается и никогда не записывается.

- **copy**: копирует `hyprland.lua` и файлы, на которые он ссылается (`require`, `dofile`, `source`, пути в `~/.config/hypr`), в новый каталог, переписывает эти пути на новое место и добавляет бинды Infinity. Остальные программы Hyprland (hyprlock, hypridle, hyprpaper и т.д.) продолжают читать свои файлы из `~/.config/hypr`.
- **fresh**: создаёт чистый конфиг из примера (`hyprland/example/hyprland.lua`), в котором бинды Infinity уже есть.
- Существующий конфиг не перезаписывается никогда. Программа настройки откажется; `--force` сначала делает резервную копию рядом (`infinity-hyprland.bak-<время>`).

Программу можно запустить позже: `/opt/infinity-hyprland/bin/infinity-hyprland-config fresh|copy-hyprland|status`.

Hyprland 0.57 читает только конфиги на Lua (`hyprland.lua`). Если у вас только старый `hyprland.conf`, режим copy откажется с пояснением, используйте fresh.

**Столкновения бинд.** Бинды Infinity добавляются в конец конфига между строками `>>> infinity-hyprland` и `<<< infinity-hyprland`. Если в вашем конфиге те же клавиши уже заняты, сработают оба бинда. Типичные случаи: `SUPER+SHIFT+SPACE` (часто медиа или лаунчер) и `ALT+TAB` (если у вас свой переключатель). Измените строки блока или свой бинд: блок это обычный Lua.

## Запуск

- **Экран входа:** выйдите из сессии и выберите **Infinity-hyprland** в меню сессий (SDDM, GDM, greetd и др.).
- **С TTY** (безопаснее всего для первого запуска, текущая сессия остаётся жить): переключитесь на свободную TTY (`CTRL+ALT+F3`), войдите и выполните `/opt/infinity-hyprland/bin/infinity-hyprland-session`.

Обёртка сессии выставляет `XDG_CURRENT_DESKTOP=Infinity-hyprland:Hyprland` (чтобы порталы и приложения, которые ждут «Hyprland», продолжали работать), указывает композитору ваш конфиг и запускает его через `start-hyprland`, который перезапускает композитор в безопасном режиме после сбоя.

## Обновления из приложения

- Сессия раз в 6 часов проверяет GitHub и показывает уведомление, когда вышел новый релиз. Настройки (`SUPER+I`) → **About**: версии и кнопки **Changelog**, **Check** и **Update** (ниже: информация о железе и системе).
- **Update** открывает терминал и запускает `infinity-update run` (можно и вручную): клонирует тег релиза в `~/.local/share/infinity-hyprland/src`, собирает, запускает `install.sh --plain --yes --config skip` и спрашивает пароль sudo. Конфиги остаются. Чтобы запустить новую версию, выйдите из сессии и войдите снова.
- Библиотеки: `install.sh` копирует в `/opt/infinity-hyprland/lib` те библиотеки Hyprland, с которыми собран композитор, поэтому системное обновление `aquamarine`, `hyprutils` и подобных не ломает установленную версию. Если всё же не стартует, сессия входит в обычный Hyprland и показывает уведомление (журнал: `~/.local/state/infinity-hyprland-fallback.log`).

## Удаление

```sh
./install.sh --uninstall
```

Удаляет `/opt/infinity-hyprland` и пункт входа. `~/.config/infinity-hyprland` остаётся, удалите его вручную, если он не нужен.

## Ручная сборка и разработка

```sh
scripts/fetch-subprojects.sh
cmake -S hyprland -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build -j3
dev/run-nested.sh        # запускает build/InfinityHyprland в окне внутри текущей Wayland-сессии
```

На слабых машинах используйте лимит памяти, например `systemd-run --user --scope -p MemoryMax=6G -p MemorySwapMax=0 nice -n 19 cmake --build build -j3`; сборка с `-j$(nproc)` может исчерпать память всей системы.

Для вложенного запуска конфиг `dev/hyprland.lua` (главный модификатор `ALT`, переключатель окон на `CTRL+TAB`, потому что `SUPER` и `ALT+TAB` обычно занимает внешняя сессия). Второй монитор во вложенную сессию добавляется командой `hyprctl output create wayland`.

Другие дистрибутивы: поставьте зависимости Hyprland 0.57 (имена пакетов Arch в `installer/arch-deps.txt`), соберите как выше и установите `cmake --install build --prefix /ваш/префикс`. Файлы из `installer/` (обёртка сессии, программа настройки, `.desktop`) работают на любом дистрибутиве; замените в них `@PREFIX@`.

## Если что-то не так

- **Чёрный экран или вылет при входе:** переключитесь на другую TTY (`CTRL+ALT+F2`/`F3`). Композитор сам перезапустится в безопасном режиме. Лог: `$XDG_RUNTIME_DIR/hypr/*/hyprland.log`.
- **Клавиша делает другое или дважды:** см. «Столкновения бинд» выше.
- **Плагины из `hyprpm` не загружаются:** плагины привязаны к точной сборке Hyprland, а этот форк другая сборка.
- **`hyprctl` не подключается:** используйте `/opt/infinity-hyprland/bin/hyprctl`; `hyprctl` другой версии Hyprland может не подойти.
